## 真实根因
1. **触发机制脆弱** — 让 14B 模型说"开始执行"或产生"？"作为触发词太不可靠
2. **按钮绑定时机问题** — `[[OPTIONS]]` 在 stream_end 之后才被 smartMd 渲染，但点击事件要 scroll() 后才绑定
3. **云端同步不可靠** — 频繁 commit + git pull 没跟上，调试时一直猜原因

## 如果重来，应该这样设计
- **Level 3 直接启动流水线**——不在中间放"前台收集 + 触发词检测 + 按钮"
- **不依赖 LLM 说特定词**——触发机制要么是显式 button、要么是规则匹配
- **工作守则让 LLM 自由发挥**——LLM 决定什么时候说"够了"，系统只检测意图而不是文本
