## 一、Fork + PR 操作总步骤

> 以下为基于该官方仓库常见提交惯例的通用流程；**如官方赛题页 / 仓库 README 对目录结构、分支命名、子仓库路径有明确规定，请以官方赛题页 / README 为准**，本文不编造具体路径或命令。

1. **打开官方仓库**
   访问 `https://github.com/AMD-DEV-CONTEST/Radeon-hackathon-2026-07`（具体地址以官方赛题页为准），确认赛道二的提交要求与截止时间。

2. **Fork 到个人账号**
   点击页面右上角 **Fork**，将该仓库 Fork 到你的 GitHub 账号下（产生 `你的账号/Radeon-hackathon-2026-07`）。

3. **克隆你的 Fork 到本地**
   ```bash
   git clone https://github.com/<你的GitHub账号>/Radeon-hackathon-2026-07.git
   cd Radeon-hackathon-2026-07
   ```

4. **创建提交分支（可选 / 以官方为准）**
   建议新建一个清晰的提交分支，例如：
   ```bash
   git checkout -b track2-myagent-submission
   ```
   （若官方要求直接 push 到特定分支，请以其要求为准。）

5. **放入四件套材料**
   将本项目的四件套按官方要求的目录结构放入（**具体子目录路径以官方赛题页 / README 为准**）。本仓库对应的本地材料位置：
   - 说明文档：`docs/项目说明文档.md`
   - 源码：本 GitHub 仓库 `https://github.com/bry9107795553/MyAgent`（或你本地的最新工程目录）
   - 视频：PENDING（待云实例就绪后补充 `docs/演示视频.mp4` 或官方指定路径）
   - PPT：`ppt_competition/MyAgent_Competition.pptx`

6. **提交并推送到你的 Fork**
   ```bash
   git add -A
   git commit -m "Track 2 submission: MyAgent"
   git push origin track2-myagent-submission
   ```

7. **回到官方仓库提 PR**
   在 `https://github.com/AMD-DEV-CONTEST/Radeon-hackathon-2026-07` 页面点击 **New Pull Request** → 选择你的分支 → 填写 PR 标题与描述（见下文二三节）→ 提交。

8. **等待审核 / 补充**
   关注 PR 评论区，按评审意见补充材料（尤其是 PENDING 项就绪后，追加视频与测速并更新 PR 描述）。

## 二、PR 标题格式

请严格使用以下格式（占位符由你填写）：

```
Track 2, <姓名>, <应用名>
```

示例：

```
Track 2, 张三, MyAgent
```

- `Track 2` 为固定前缀，表示赛道二；
- `<姓名>` 填写参赛者真实姓名（或与报名一致的名称）；
- `<应用名>` 填写应用名称，本应用为 **MyAgent**。
